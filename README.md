# ComfyUI-Studio-Nodes

High-performance image enhancement, color calibration, and render utility suite for ComfyUI.

## Features

- **Color Calibration & Protection**: Advanced color fidelity transfer and tone balancing.
- **Perspective & Projection Controls**: Smooth projection transformations and viewing tools.
- **Latent Processing**: Multi-reference latent conditioning and fast scheduler primitives.
- **High-Definition Upscaling**: Integrated SeedVR2 upscaler pipeline and model loaders.

## Installation

Inside your ComfyUI root directory:

```bash
cd custom_nodes
git clone https://github.com/qiushengdesing/ComfyUI-Studio-Nodes.git
```

Restart ComfyUI. All nodes will be automatically loaded and registered.

## Requirements

Install requirements via pip:

```bash
pip install -r requirements.txt
```
